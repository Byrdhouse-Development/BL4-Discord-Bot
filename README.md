Unless otherwise noted the code was generated by Gemini Flash 2.5 using the following prompts:

|**Prompt**|***Result***|***Reason***|
|:--------:|:----------:|:----------:|
|I want you to help me make a discord bot. I have plenty of experience with javascript, but no knowledge on making a bot for discord. I would like it to be able to ping a server about when a new "code" is uploaded to an external website|*Created the initial iteration of mainBot.js along with a setup guide on how to connect everything properly with a discord bot.*|*The prompt speaks for my reasoning*|
