# BL4-Discord-Bot
Discord bot that pings a server when a new Shift Code is added to: https://www.ign.com/wikis/borderlands-4/Borderlands_4_SHiFT_Codes 

Unless otherwise noted the code was generated by Gemini Flash 2.5 using the following prompts:

|**Prompt**|***Result***|***Reason***|
|:--------:|:----------:|:----------:|
|I want you to help me make a discord bot. I have plenty of experience with javascript, but no knowledge on making a bot for discord. I would like it to be able to ping a server about when a new "code" is uploaded to an external website|*Created the initial iteration of mainBot.js along with a setup guide on how to connect everything properly with a discord bot.*|*The prompt speaks for my reasoning*|
|How best should I use a version manager like github integrated with this app|*This generated the .env and .gitignore files, and modified the mainBot.js file to keep sensitive information in the .env file to ensure I am the sole owner of the bot while I wish to allow others to modify this bot's abilities.*|*I knew I would need a .gitignore file for adding this app to GitHub, but I didn't consider the safety risks that Gemini recommended to avoid by incorporating the .env file.*|
|Would I benefit much from adding containerization to this with docker|*This returned with a Dockerfile and docker-compose.yml to utilize the .env files. Provided brief tutorial on how to add it to docker and utilize the containerization*|*I have touched containers once in my schooling in the past, so I wanted to see the capability of AI to assist in incorporating the app to containerization.*|
